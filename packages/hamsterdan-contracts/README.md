# hamsterdan-contracts

Hamsterdan's data model, ported from `upstream/hamsterdan`. It contains:

- every workflow contract in `src/hamsterdan/contracts`;
- the agent protocol types in `src/hamsterdan/agents/protocol.py`;
- the Python-literal printer and parser. The dashboard stores Python `repr()`
  text and the board reads it back with `ast.literal_eval`, so both directions
  must match CPython exactly.

Each contract's JSON spelling and admission match the pinned pydantic byte for
byte. Committed corpora, generated by running the pinned Python, prove it (see
[PARITY.md](PARITY.md)). Where the Haskell design differs on purpose, the
change is recorded in [DIVERGENCES.md](DIVERGENCES.md). No wire format
diverges.

## How the codecs work

A `Codec a` pairs an encoder and a strict decoder. A record codec builds both
from one applicative field list, so encode order and decode admission cannot
drift apart:

- Encoding writes every field, defaults included, in declaration order. This is
  `dump_python(mode="json")`.
- Decoding does what `validate_json` does in strict mode:
  - JSON types must match exactly (no int/float/bool/str coercion);
  - unknown members are refused (`extra="forbid"`);
  - a missing member is refused unless the field has a default;
  - `Literal` fields are compared by Python equality (so `Literal[0]` admits
    `false` and `0.0`);
  - `Any` and `dict` values keep non-finite floats and dump them as `null`.

Generated records use `recordWith`, which adds a positional fast path. When the
input's members are exactly the declared ones, in declaration order (which is
always true of a pydantic dump), values are decoded by position, with no lookup
table. Any other input takes the general path. Both paths are checked against
the corpus, and every valid row is also decoded with its members reversed.

The record modules are generated from the upstream dataclasses by
`scripts/gen_models.py`. Nothing is copied by hand, so the field lists cannot
drift from the pin. To regenerate:

```sh
upstream/hamsterdan/.venv/bin/python packages/hamsterdan-contracts/scripts/gen_models.py
upstream/hamsterdan/.venv/bin/python packages/hamsterdan-contracts/scripts/gen_printable.py
```

## Python literals

`dictEntry` and `sortedItemsDigest` print a JSON body straight into a single
buffer. `repr` prints any `PyValue` (lists, tuples, dicts with non-string keys).

`literalEval` parses the full literal grammar of the modeled types:

- string prefixes, triple quotes, every escape;
- implicit concatenation;
- every integer base, underscores, and the 4300-digit limit;
- signed numbers, comments, line continuations, trailing commas;
- the nesting limit.

It sorts failures the way `board.py` needs them sorted:

- `Malformed` is CPython's `SyntaxError` or `ValueError`, which the board skips.
- `Unhashable` is CPython's `TypeError`, which propagates in Python.
- `Unsupported` covers literals CPython accepts but whose type is not modeled:
  bytes, complex, sets, `Ellipsis`, lone surrogates, and `\N{...}`.

## Tests and corpora

```sh
cabal test hamsterdan-contracts
```

The corpora under `test/corpus/` were generated by the committed scripts
running in the pinned Python (`upstream/hamsterdan/.venv`, Python 3.14.6,
pydantic 2.13.4, pydantic-core 2.46.4). The suite replays every row and
compares bytes.

| --- | --- | --- |
| `contracts.jsonl` (`validate_json` admission and `dump_python` spelling of all 159 models) | 6998 | `scripts/gen_corpus.py` |
| `projection.jsonl` (`project_readiness`, digest, wait, gates) | 400 | `scripts/gen_corpus.py` |
| `repr.jsonl` (16780 `repr` values, 600 dashboard entries and digests) | 17380 | `scripts/gen_corpus.py` |
| `literal_eval.jsonl` | 4608 | `scripts/gen_corpus.py` |
| `protocol.jsonl` (`asdict` + `json.dumps`, plain and identity spellings) | 600 | `scripts/gen_protocol_corpus.py` |

To regenerate the corpora (the generators are seeded and deterministic):

```sh
upstream/hamsterdan/.venv/bin/python packages/hamsterdan-contracts/scripts/gen_corpus.py
upstream/hamsterdan/.venv/bin/python packages/hamsterdan-contracts/scripts/gen_protocol_corpus.py
```
