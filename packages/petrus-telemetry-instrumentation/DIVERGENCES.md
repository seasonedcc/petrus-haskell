# petrus-telemetry-instrumentation: divergences

None of its own. This package has no library: it holds the evidence for
the `impetus_*` events that `petrus-impetus`, `petrus-engine` and
`petrus-history-store` emit through `petrus-telemetry`. Their differences
from the reference's events are recorded with the telemetry library, in
[`petrus-telemetry/DIVERGENCES.md`](../petrus-telemetry/DIVERGENCES.md)
("The instrumentation", items 15 onward).
