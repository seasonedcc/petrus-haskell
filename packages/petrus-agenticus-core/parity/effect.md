## Beyond the upstream tests

Golden vectors from docs/runtime.md §11 Effect §2:

- `digest_payload({"message": "ready"})`
- the test proposal's canonical bytes and digest
- raw UTF-8 for non-ASCII text
- the code and digest grammars

Differential replay of `differential/effect_corpus.json`, generated by
`differential/effect_corpus.py` against the reference:

- **302 `digest_payload` cases.** Each case checks the exact canonical text
  and digest, or the refusal class and message. The payloads cover:
  - controls, quotes, backslashes, DEL, U+0085, U+2028, U+FEFF, U+FFFF,
    astral characters and code-point key ordering;
  - integers up to ±10^100;
  - floats, NaN, ±Infinity, and non-object roots.
- **60 `EffectProposal.digest` cases** over generated proposals.
- **1 577 `from_data` cases** across all seven value types. Each case is
  checked against `json.dumps(to_data())` bytes, or the exact refusal class
  and message. They cover:
  - the valid data;
  - single-field hostile mutations;
  - missing and extra keys;
  - nested mutations;
  - the full cross products of lookup disposition × receipt, evidence
    recovery × receipt × fence, and decision kind × fence × evidence ×
    reason.
- **51 gateway cases.** Every reachable scripted path is run for two
  proposals: lookup, fence, execute and recovery-lookup outcomes. Each path
  checks the decision bytes and the exact provider call trace. Seven cases
  are refusals before any provider call.

## Gaps

None of the upstream behaviour is missing. Two upstream refusals cannot be
reached, because the Haskell types exclude their inputs:

- the non-string-key and tuple payloads;
- "wrong return type" answers from adapters and fence sources.

Both are recorded in `divergences/effect.md`.
